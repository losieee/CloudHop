# 2스테이지 미끄럼 언덕

29번 발판은 평평한 진입부와 오른쪽 내리막으로 이어지는 얼음 비탈입니다. 밟으면 자동으로 오른쪽 아래로 미끄러지고, 연결된 30번 평지에서 멈춥니다. 31~32번 발판으로 다시 올라갑니다. PC와 Android는 동일한 씬과 동작을 사용합니다.

- 미끄러지는 중에도 기존 점프 충전/해제가 가능합니다.
- 세 캐릭터는 기존 Charge 자세에 기울기, 약한 흔들림을 더합니다. 별도 신규 프레임을 생성한 애니메이션은 아닙니다.
- 점프하거나 바닥에 도착하거나 재시작하면 원래 자세로 복원됩니다.
- 비탈에서는 중앙 정확 착지 판정을 사용하지 않습니다. 기존 발판의 콤보 기능은 유지됩니다.
- `SlidingSlope`의 이동 속도/각도와 `SlideMapInstaller`의 PolygonCollider2D 및 메시가 지형을 정의합니다. 평지·비탈·출구의 접점은 함께 조정해야 합니다.
- 맵 재적용 순서는 RidgeMapInstaller 후 SlideMapInstaller입니다. RidgeMapInstaller만 재실행하면 출구 높이와 코인이 기본 능선 배치로 돌아갑니다.
- 미끄럼 구간 이후 코인 총 가치는 HUD에서 데이터 합산으로 표시됩니다.
