# 공통 2스테이지: 바람 능선

PC와 Android는 동일한 CloudHop 씬과 Stage02_Normal 데이터를 사용합니다.

- 12~16번: 구름 계단을 올라 능선으로 진입합니다.
- 16~20번: 기존 하단 경로와 Golden Ridge Route의 상단 3개 발판 중 선택합니다. 상단은 좁은 발판과 큰 높이차에 대한 보상으로 황금 코인을 제공합니다. 두 경로의 점프 횟수는 같습니다.
- 28~32번: 작은 섬을 계단식으로 오르내립니다.
- 33~40번: 높낮이가 반복되는 능선입니다. 기존 이동 발판의 진폭은 0.4, 주기는 4.8초입니다.
- 41~48번: 정상(높이 2.8)을 거쳐 도착 지점으로 내려옵니다.
- 기존 8번/24번 콤보 지름길과 11번/27번 상승기류를 유지합니다. 새의 위치는 새 지형 높이에 맞춰 조정했습니다.

구름 코인 136개, 총 가치 152점입니다. 시간제 기믹 구간에는 고정된 점프 궤적을 잘못 안내하지 않도록 코인 곡선을 생략했습니다. 수집량은 시도별로 표시하며 재시작 시 복원됩니다. 시간 랭킹에는 영향을 주지 않습니다.

맵은 공통 씬에서 직접 편집하고 코인은 Stage02_Normal의 coins 배열에서 관리합니다. `Cloud Hop > 맵 > 공통 2스테이지 바람 능선 적용`은 기본 배치를 재적용하므로 수동 조정 후 실행하면 해당 구간을 덮어씁니다.
