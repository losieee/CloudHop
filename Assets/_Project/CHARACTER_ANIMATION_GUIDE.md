# 소녀·여우 동작 애니메이션

업로드한 원본 PNG 10장을 그대로 사용하며, 메인 캐릭터와 같은 CharacterVisual의 상태별 스프라이트 전환으로 동작합니다.

| 동작 | 소녀 원본 | 여우 원본 | 전환 조건 |
| --- | --- | --- | --- |
| 대기 | 캐릭터 1.png | 캐릭터 6.png | 발판 위에서 대기 |
| 충전 | 캐릭터 2.png | 캐릭터 7.png | 점프 버튼을 누르고 충전 |
| 점프 | 캐릭터 3.png | 캐릭터 8.png | 공중에서 상승 |
| 착지 | 캐릭터 4.png | 캐릭터 9.png | 공중에서 발판에 착지한 뒤 0.16초 |
| 낙하 | 캐릭터 5.png | 캐릭터 10.png | 공중에서 하강 |

- 스프라이트: `Art/Characters/Girl` 및 `Art/Characters/Fox`.
- 데이터: `ScriptableObjects/GirlCharacter.asset`, `FoxCharacter.asset`. 기존 선택 화면의 참조를 그대로 사용합니다.
- 같은 캐릭터의 모든 자세는 동일한 픽셀당 크기를 사용합니다. 이미지의 투명 여백과 발 위치는 스프라이트 피벗으로 정렬합니다.
- 충전은 착지 자세보다 우선합니다. 다시 시작하면 이전 충전/착지 상태를 지우고 대기로 초기화합니다.
- 플레이어의 충돌 크기, 점프 속도 및 입력 방식은 변경하지 않습니다.
- 메인 캐릭터처럼 동작당 한 장을 전환하는 방식입니다. 원본에 없는 중간 프레임을 생성하는 방식은 아닙니다.
- 메인 캐릭터처럼 착지 이미지가 없는 기존 데이터는 대기 이미지로 대체합니다.

임포트 설정을 다시 만들려면 Unity 메뉴 `Cloud Hop > Install Additional Character Poses`를 실행합니다. 이미 연결된 상태이므로 평소에는 실행할 필요가 없습니다.

`CharacterPoseTests`는 두 캐릭터의 실제 점프 물리 동작, 착지 복귀, 즉시 재충전, 재시작 초기화 및 충돌 크기를 검사합니다. `GameUITests`와 `ExhibitionUITests`는 캐릭터 선택과 3스테이지 기록 등록 흐름을 검사합니다.
