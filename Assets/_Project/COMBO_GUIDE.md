# 콤보와 선택 경로

새 발판의 청록색 중앙 영역에 연속 3번 착지하면 부스트 1회를 얻습니다. 스페이스바를 누르고 있다가 떼면 점프하고, 부스트를 가지고 공중에서 다시 누르면 앞으로 짧게 가속합니다. 왼쪽 마우스도 같은 동작입니다.

- 부스트는 최대 1회 보관하며 한 점프에 한 번 사용합니다. 6, 9… 콤보에서도 비어 있는 부스트를 충전합니다.
- 중앙 밖 착지, 발판 재방문, 피격은 콤보를 끊지만 확보한 부스트는 유지합니다. 재시도와 스테이지 전환은 둘 다 초기화합니다.
- 부스트는 0.24초 동안 수평 속도 14, 이후 기존 속도 5로 돌아옵니다. 낙하 중 사용 시 최소 상승 속도 2.4를 줍니다.
- 중앙 판정은 발판 폭의 쉬움 50%, 보통 40%, 어려움 32%이며 최대 전체 폭 1.6입니다.

## 선택 구간

발판 번호는 시작 발판을 0으로 셉니다. 통합 씬 `Scenes/CloudHop.unity`에 적용됩니다.

| 스테이지 | 출발 → 기본 경로 → 합류 | 특징 |
| --- | --- | --- |
| 1 | 3 → 4 → 5 | 부스트 사용을 익히는 기존 시험 구간 |
| 2 | 8 → 9 → 10 | 낮고 넓은 중간 발판 또는 공중 부스트 지름길 |
| 2 | 24 → 25 → 26 | 충전량을 바꿔 도전하는 두 번째 지름길 |
| 3 | 10 → 11 → 12 | 상승기류와 부스트를 결합하는 높은 합류 발판 |
| 3 | 19 → 20 → 21 | 움직이는 출발 발판과 번개 타이밍을 함께 판단 |

금색 곡선은 지름길의 방향을 안내하며 실제 점프 궤적을 보장하지 않습니다. 기본 경로는 부스트 없이 진행할 수 있고, 2스테이지의 넓은 중간 발판은 짧은 점프의 회복 지점을 겸합니다. 상승기류와 번개는 주기적으로 켜지므로 안전한 타이밍을 기다릴 수 있습니다. 지름길은 중간 발판에 착지하고 다시 충전하는 과정을 줄입니다.

## 관리

- 문구: `Data/UITexts.xlsx`의 기존 `combo.*` 항목. 저장 후 기존 임포터로 반영됩니다.
- 선택 구간: `ScriptableObjects/Stages/Stage*.asset`의 `choiceRoutes`. 출발/중간/합류 발판 인덱스와 안내 곡선 높이를 관리합니다.
- 배치 재적용: `Cloud Hop > Install Stage Choice Routes`. 통합 씬과 해당 스테이지 데이터를 기본 선택 경로 배치로 갱신하므로 수동 배치 수정 후에는 주의해서 사용합니다.
- 물리 수치: `PlayerController`의 Combo boost 항목. 규칙은 `ComboChain`, 효과는 `ComboEffects`, 중앙 표시는 `PerfectLandingZone`.
- 안내 곡선은 `ComboShortcutGuide`, 화면 문구는 `GameUICombo`. 이동 발판 위치를 따라 갱신합니다.
- 로컬 랭킹의 측정·저장 규칙과 기존 기록은 유지합니다. 사람의 조작감과 전체 코스 난이도는 전시 전 플레이테스트가 필요합니다.
