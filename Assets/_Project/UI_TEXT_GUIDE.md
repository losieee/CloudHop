# UI 문구 엑셀 관리

수정 파일: `Data/UITexts.xlsx`

1. Unity의 `Cloud Hop > UI 텍스트 > 엑셀 열기`를 누르거나 파일을 직접 엽니다.
2. `UI텍스트` 시트의 노란색 **한국어** 열을 수정합니다. 화면 열의 필터로 일시정지, 결과, 랭킹 등을 찾을 수 있습니다.
3. 저장하고 Unity로 돌아옵니다. 자동으로 게임용 문구 데이터가 갱신됩니다. 플레이 중이었다면 중지하고 다시 실행합니다.
4. 자동 반영이 안 되면 `Cloud Hop > UI 텍스트 > 엑셀 다시 반영`을 선택합니다.
5. 배포할 때는 게임을 다시 빌드합니다. 빌드 전에도 원본 엑셀을 다시 검증하고 반영합니다.

## 관리 범위

통합 `CloudHop` 씬의 로비, 캐릭터 선택과 이름, 스테이지 선택과 이름, 플레이 화면, 일시정지, 설정, 닉네임 입력, 결과, 랭킹의 표시 문구와 콤보·부스트·시험 지름길 안내를 포함한 69개입니다. 동일한 공통 버튼은 하나의 Key를 공유합니다. 참가자의 실제 닉네임, 점수, 기록 시간은 게임에서 채워집니다.

`Key`와 시트 이름은 유지하세요. 행 정렬과 필터는 자유롭게 사용할 수 있습니다. `{0}`, `{1}`, `{2}`는 변수 설명에 적힌 게임 데이터가 들어갈 자리입니다. 줄바꿈은 셀에서 Alt+Enter를 사용합니다. 색상과 크기 태그가 있는 문구는 해당 태그를 유지하면 기존 강조 디자인이 유지됩니다.

빈 문구, 중복·누락 Key, 잘못된 변수, 수식이 들어간 셀은 반영을 거절하고 Unity 콘솔에 오류를 남깁니다. 마지막 정상 데이터는 유지되며, 문제가 해결되기 전에는 새 빌드를 만들지 않습니다. 화면에 맞도록 문구 길이를 조절하고 긴 문구는 실행해서 확인하세요.

## 데이터 흐름

`Data/UITexts.xlsx` → 에디터 임포터 → `Resources/UITexts.json` → `UIText.Get` → 실제 UI

JSON은 자동 생성 파일이므로 직접 수정하지 않습니다. 게임 실행 파일에는 이 데이터가 포함되므로 Excel 설치나 네트워크 연결이 필요 없습니다. 완성된 실행 파일 옆에 엑셀만 복사해서 문구를 바꾸는 방식은 아닙니다.

새 UI 항목을 개발할 때는 `UITextSchema`의 Key와 변수 개수, 엑셀 행, 해당 UI의 `UIText.Get` 호출을 함께 추가합니다. 이전 프로토타입/기믹 실험 씬의 개발용 HUD는 통합 게임 UI와 별개입니다.

## 화면 전체 배경

일시정지, 설정, 결과 등 화면 루트의 앵커를 캔버스 전체로 늘리고 여백을 0으로 설정했습니다. 고정 크기의 메뉴 배치는 가운데에 유지하면서 반투명 배경이 화면 비율에 맞춰 끝까지 채워집니다.

검증: 1920×1080, 2560×1080, 1024×768 화면의 모달 영역과 UI 배치, 기존 로비·캐릭터 선택·랭킹 흐름, 엑셀 문구 및 변수 검증, 행 재정렬·따옴표·줄바꿈 읽기.
